Skills

できること

実際に自分の作品で使っている技術です。

  • モバイルアプリ

    Flutter / Dart でiOS向けアプリを開発しています。状態管理にRiverpod、端末内データベースに drift（SQLite）を使い、通信を伴わないオフライン動作のアプリを作ってきました。

  • Webアプリケーション開発

    TypeScript / Next.js / PostgreSQL と、PHP / CodeIgniter / MariaDB の両方で、打刻・勤怠・給与のような業務ドメインをデータベース設計から画面まで実装します。

  • Webサイト制作

    HTML / CSS / JavaScript を直接書いてサイトを組み立てます。ビルド工程やフレームワークに頼らない構成と、スマートフォンからデスクトップまでのレスポンシブ対応が中心です。

  • スクリプトによる自動化

    PowerShell / Python で、繰り返しの作業や検証手順をスクリプト化します。画面のスクリーンショット取得やリンク切れ検査といった、確認作業の自動化も含みます。
